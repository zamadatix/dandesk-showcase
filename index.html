DanDesk brings the desktop shell, everyday applications, and system controls into one native Wayland application. A shared Vulkan renderer, theme system, and text engine tie it all together—from the taskbar to a document’s pixels. Dense interfaces, per-monitor HDR, GPU image reconstruction, and native input sharing make it feel built as a system.

01

One resident application

The shell and its tools share a C23 process. Owner threads separate responsibilities; demanding numeric and codec jobs use short-lived, contained helpers.

02

One rendering foundation

Vulkan presentation, shared text shaping, color handling, and GPU sinc image reconstruction carry across the desktop, applications, and dialogs.

03

One set of building blocks

Settings, themes, menus, reports, editors, and accessibility semantics are shared. Hyprland, PipeWire, BlueZ, and other host services keep their own roles.
