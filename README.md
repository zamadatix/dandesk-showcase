# DanDesk showcase

A concise public tour of DanDesk's native Linux desktop shell, applications, panels, and shared foundations.

The 32 selected views were captured from the live top 3840×2160 display on October 22, 2026, using DanDesk's official `capture_screen` action through its message bus. The native HDR capture path produces tone-mapped sRGB PNGs. Published WebP assets are crops or optimized copies of those captures. The tour uses sample documents and messages, and excludes private content from the selected crops.

The site is buildless HTML, CSS, and JavaScript. Serve this directory with any static HTTP server. `data.js` contains the concise component descriptions and gallery selections; `assets/images.json` records the published image sizes.

This repository contains only the showcase. It does not contain the private DanDesk implementation, system configuration, or raw capture records.
